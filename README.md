# 수학질문방 iOS 앱

[수학질문방](https://suhakjilmoon.pages.dev) 사이트를 아이폰 앱으로 감싼 것이다.
사이트 원본은 [qkfmswlrma/math](https://github.com/qkfmswlrma/math) 에 있고, 여기는 앱 껍데기만 있다.

화면과 기능은 사이트와 완전히 같다. 앱이 따로 하는 일은 네 가지다.

- 화면을 아이폰 끝까지 쓰고, 노치와 홈 표시줄을 피해 여백을 잡는다
- 사이트가 인터넷에서 받아오던 React, Supabase, KaTeX, MathLive, 글꼴을 앱 안에 넣는다
- 화면 모드에 맞춰 위쪽 시계와 배터리 글자색을 바꾼다
- 앱을 켤 때 뜨는 시작 화면을 사이트가 준비되는 순간에 맞춰 내린다

---

## 어떻게 만들어지나

```
../수학/index.html          사이트 배포본
        │
        │  node scripts/prepare-www.js
        │   · CDN 주소를 앱 안 파일로 바꾼다
        │   · 안전 여백 css 와 app-native.js 를 끼워 넣는다
        ▼
      www/                  앱에 들어갈 웹 자산
        │
        │  npx cap sync ios
        ▼
  ios/App/App/public/       Xcode 프로젝트 안
        │
        │  xcodebuild  (맥에서만 된다)
        ▼
      App.app / ipa
```

**아이폰 앱은 맥에서만 빌드된다.** 윈도우에서는 프로젝트를 만들고 고치는 것까지만 되고,
실제 컴파일은 `.github/workflows/ios.yml` 이 깃허브가 빌려주는 맥에서 돌린다.

---

## 사이트가 바뀌었을 때

사이트를 고치고 배포했다면 앱도 다시 만들어야 한다. 앱은 웹 자산을 안에 넣어두기 때문에
사이트만 바뀐다고 앱이 따라 바뀌지 않는다.

```bash
npm run sync
```

`prepare-www` 로 최신 사이트를 가져오고, `cap sync` 로 iOS 프로젝트에 넣고,
사이트의 `APP_VERSION` 을 앱 버전으로 맞춘다. 그다음 커밋해서 올리면 깃허브가 빌드한다.

사이트 폴더가 `../수학` 이 아니면 이렇게 알려준다.

```bash
SITE_DIR=경로 npm run sync
```

### 아이콘을 새로 만들 때

사이트의 `icon-512.png` 가 바뀌었을 때만 하면 된다.

```bash
node scripts/make-icons.js
npx @capacitor/assets generate --ios --assetPath assets
```

## 폴더

| 경로 | 무엇 |
|---|---|
| `www/` | 앱에 들어가는 웹 자산. **직접 고치지 않는다.** `prepare-www.js` 가 만든다 |
| `scripts/prepare-www.js` | 사이트를 앱용으로 바꾸는 곳 |
| `scripts/app-native.css` | 노치와 홈 표시줄을 피하는 여백 보정 |
| `scripts/app-native.js` | 상태 표시줄 색, 시작 화면 내리기 |
| `scripts/fix-ios.js` | `cap sync` 뒤처리와 버전 맞추기 |
| `scripts/make-icons.js` | 아이콘과 시작 화면 그림 만들기 |
| `ios/` | Xcode 프로젝트 |
| `assets/` | 아이콘 원본 1024, 시작 화면 원본 2732 |

## 지금 상태와 앞으로 필요한 것

깃허브 액션은 **서명하지 않은** 앱까지 만든다. 코드가 제대로 컴파일되는지는 여기서 다 확인된다.
받은 `.ipa` 는 그대로는 아이폰에 못 넣는다. 애플이 서명 없는 앱을 막기 때문이다.

실제 아이폰에 넣거나 앱스토어에 올리려면 애플 개발자 계정이 필요하다.

| 하고 싶은 것 | 필요한 것 |
|---|---|
| 시뮬레이터에서 보기 | 맥 + Xcode. 계정 필요 없음 |
| 내 아이폰에 넣기 | 무료 애플 ID 로 Xcode 에서 실행. 7일마다 다시 넣어야 함 |
| 남에게 나눠주기(TestFlight) | 유료 개발자 계정 (연 129,000원) |
| 앱스토어 출시 | 유료 개발자 계정 + 심사 |

계정이 생기면 Xcode 에서 `ios/App/App.xcodeproj` 를 열고 Signing & Capabilities 에서
팀만 고르면 된다. 번들 아이디는 `app.mathroom.suhakjilmoon` 이다.

### 앱스토어 심사에 대해

사이트를 그대로 감싸기만 한 앱은 애플이 반려하기도 한다(심사 지침 4.2).
지금은 웹 자산을 앱 안에 넣어 인터넷 없이도 화면이 뜨고, 사진 올리기와 시작 화면,
화면 모드 연동처럼 앱다운 부분을 넣어두었다. 그래도 심사에서 더 요구할 수는 있다.

## 왜 이렇게 했나

**CDN 을 앱 안으로 옮긴 이유.** 사이트는 React 와 KaTeX 를 인터넷에서 받아온다.
웹에서는 그게 맞지만 앱에서는 첫 화면이 뜨기까지 네트워크를 기다리게 되고,
CDN 이 잠깐 죽으면 앱이 흰 화면이 된다. 그래서 `prepare-www.js` 가 전부 앱 안에 넣고,
바깥 주소가 하나라도 남으면 빌드를 세운다.

**사이트 원본을 고치지 않는 이유.** 앱 때문에 사이트 코드에 앱 전용 분기가 끼면
사이트와 앱이 서로를 갉아먹는다. 그래서 앱에 필요한 것은 전부 이 저장소에서
덧붙이는 방식으로만 넣는다. `../수학` 폴더는 읽기만 한다.
